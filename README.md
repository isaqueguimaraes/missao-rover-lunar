# Missão Rover Lunar 🚀

Projeto desenvolvido como parte da disciplina de **Garantia da Qualidade de Software** e **Gestão e Qualidade de Software**, sob orientação do Professor **Daniel Henrique Matos de Paiva**.

## 📌 Sobre o Projeto
Este repositório tem como objetivo praticar o fluxo de trabalho colaborativo no Git/GitHub (Git Flow), contemplando a criação de repositórios, gerenciamento de branches (`develop` -> `main`), commits estruturados e abertura/aprovação de Pull Requests (PR).

O script principal inicializa os sistemas básicos de um Rover Lunar, validando seus painéis solares e o nível de bateria.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Controle de Versão:** Git e GitHub
